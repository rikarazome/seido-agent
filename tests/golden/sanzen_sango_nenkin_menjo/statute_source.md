# 産前産後の国民年金保険料免除 — 出典固定

**状態: VERIFIED（2026-06-22, 日本年金機構ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 免除期間 | 出産月の前月から4か月間 |
| 多胎妊娠 | 出産月の3か月前から6か月間 |
| 年金額反映 | 免除期間も納付済みとして老齢基礎年金に反映 |
| 対象 | 国民年金第1号被保険者（H31.2.1以降の出産） |
| 届出 | 出産予定日の6か月前から可能 |
| 出産の定義 | 妊娠85日以上（死産・流産・早産含む） |
| 付加保険料 | 産前産後期間中も納付可能 |

出典（日本年金機構ページ全文読み取り）:
- 日本年金機構: https://www.nenkin.go.jp/service/kokunen/menjo/20180810.html
- 「出産予定日または出産日が属する月の前月から4カ月間」
- 「保険料が免除された期間も保険料を納付したものとして老齢基礎年金の受給額に反映」
