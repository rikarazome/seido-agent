# 産前産後の国民年金保険料免除

- 国民年金法88条の2: https://laws.e-gov.go.jp/law/334AC0000000141/
- 日本年金機構 産前産後の免除制度: https://www.nenkin.go.jp/service/kokunen/menjo/20180810.html

## 制度概要（国民年金法88条の2・年金機構公式より）
- 国民年金第1号被保険者が出産した場合
- 出産予定日の前月から4か月間（多胎は6か月間）の保険料が免除
- 免除期間は満額の基礎年金として計算される（通常の免除と異なり年金額に反映）
- 所得要件なし
- 2019年4月施行

- ninshin=true（妊娠中）で判定。国民年金法88条の2の対象要件と直接対応。
