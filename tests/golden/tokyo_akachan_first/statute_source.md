# 赤ちゃんファースト（東京都） — 出典固定

**状態: VERIFIED（2026-06-15）**

| 項目 | 確定値 |
|---|---|
| 支給額 | 子ども1人あたり10万円相当のポイント（専用カタログから育児用品等と交換） |
| 対象 | 都内在住で出生した児童（出生届提出+面談完了が条件） |
| 所得制限 | **なし** |
| 年齢要件 | 出生した児童。判定上は「0歳」（1歳年度末以前）を基準とする |
| 実施期間 | R5年度〜（継続中） |

出典:
- 東京都福祉局: https://www.fukushi.metro.tokyo.lg.jp/kodomo/kosodate/babyfirst.html
- 東京都公式: https://akachan-first.metro.tokyo.lg.jp/

判定に使うaskable: なし（年齢のみで判定）

注: 都内在住要件は東京都制度共通の前提（自治体選択で充足）。
面談要件は判定対象外（申請手続きの案内で補足）。
v1では年度末年齢0歳（=出生年度内）の子を対象とする。
