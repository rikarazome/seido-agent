# 求職者支援制度（職業訓練受講給付金）— 出典固定

**状態: VERIFIED（2026-06-22, 厚労省ページ全文読み取り + page_snapshot保存）**

| 給付の種類 | 金額 |
|---|---|
| 職業訓練受講手当 | 月10万円 |
| 通所手当 | 定期乗車券等（月上限42,500円） |
| 寄宿手当 | 月10,700円 |

| 支給要件 | 確定値 |
|---|---|
| 本人収入 | 月8万円以下 |
| 世帯収入 | 月30万円以下 |
| 世帯金融資産 | 300万円以下 |
| 不動産 | 現住所以外に土地・建物を所有していない |
| 出席 | 訓練実施日全て（やむを得ない理由で8割以上） |
| 過去受給 | 6年以内に給付金受給していない |

| 求職者支援資金融資 | 金額 |
|---|---|
| 単身 | 月5万円×訓練月数 |
| 扶養家族あり | 月10万円×訓練月数 |
| 利率 | 2%（信用保証料0.5%含む） |
