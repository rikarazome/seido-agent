# 中野区就学援助 — 出典固定

**状態: VERIFIED（2026-06-21, 公式ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 対象 | 区内在住+国公立小中学校在籍+所得基準未満 |
| 基準額目安 | 2人世帯 約331万円、4人世帯 約439万円 |
| 費目 | 学用品費、オンライン学習通信費、新入学学用品費、給食費、クラブ活動費等 |
| 注意 | 中野区立学校は修学旅行等を保護者負担なしで実施→就学援助対象外 |
