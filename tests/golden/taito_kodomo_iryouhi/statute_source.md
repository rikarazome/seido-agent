**状態: VERIFIED（2026-06-21, 公式ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 対象年齢 | 出生から18歳到達後最初の3月31日まで |
| 助成内容 | 保険診療の自己負担分 + 入院時食事代（in_kind） |
| 要件 | 台東区住民登録 + 国民健康保険/社会保険加入 |
| 所得制限 | なし（ページに記載なし） |
| 除外 | 生活保護、児童福祉施設入所 |
| 特記 | 食事代も助成対象（後日申請で振込） |
