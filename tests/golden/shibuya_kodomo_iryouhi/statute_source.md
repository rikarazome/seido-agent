# 渋谷区子ども医療費助成 — 出典固定

**状態: VERIFIED（2026-06-21, 公式ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 対象年齢 | 0歳～18歳到達後最初の3月31日まで |
| 助成内容 | 保険診療の自己負担分 + 入院時食事代 + 補装具（in_kind） |
| 要件 | 渋谷区住民登録 + 日本の健康保険加入 |
| 所得制限 | なし（「保護者の所得制限はありません」と明記） |
| 除外 | 生活保護、健康保険未加入、児童福祉施設入所、里親委託 |
| 特記 | 食事代・補装具も対象（後日支給申請） |

出典（公式ページ全文読み取り）:
- 渋谷区公式: https://www.city.shibuya.tokyo.jp/kodomo/kodomo-teate-josei/iryo-josei/kodomo_ij.html
- 「保険診療内の自己負担分」
- 「入院時の食事療養費の自己負担分」も対象
- 「保護者（申請者）の所得制限はありません」
