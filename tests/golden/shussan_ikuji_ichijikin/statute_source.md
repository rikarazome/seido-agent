# 出産育児一時金 — 出典固定

**状態: VERIFIED（2026-06-15）**

| 項目 | 確定値 |
|---|---|
| 支給額 | 1児につき500,000円（産科医療補償制度加入機関での出産。未加入は488,000円だが本プロダクトでは加入前提で500,000円固定） |
| 対象 | 健康保険（国保・社保）の被保険者または被扶養者で妊娠4か月（85日）以上の出産（流産・死産含む） |
| 所得制限 | **なし** |
| 申請 | 直接支払制度（医療機関経由）/ 事後申請（加入保険者へ） |

出典:
- 健康保険法101条（被保険者）、114条（被扶養者）
- 厚生労働省: https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/iryouhoken/shussan/
- 全国健康保険協会: https://www.kyoukaikenpo.or.jp/g6/cat620/r310/

判定に使うaskable:
- `kenkou_hoken`: 健康保険加入（boolean）
- `ninshin`: 妊娠中か（boolean）

注: 妊娠4か月以上という詳細条件はv1では省略（妊娠中=trueで受給資格ありとする安全側判定）。
産科医療補償制度の加入/未加入による金額差（500,000 vs 488,000）もv1では500,000固定。
