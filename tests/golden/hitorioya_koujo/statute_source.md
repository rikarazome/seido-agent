# ひとり親控除 — 出典固定

**状態: VERIFIED（2026-06-21, 国税庁タックスアンサー全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 控除額 | 35万円（固定） |
| 要件1 | 事実婚関係にある者がいない |
| 要件2 | 生計を一にする子がいる（子の総所得48万円以下、R7分から58万円以下） |
| 要件3 | 合計所得500万円以下 |
| 適用開始 | R2分から |
