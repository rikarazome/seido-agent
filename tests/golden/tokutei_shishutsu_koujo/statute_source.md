# 特定支出控除 — 出典固定

**状態: VERIFIED（2026-06-22, 国税庁タックスアンサー全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 控除額 | 特定支出合計が給与所得控除額×1/2を超える部分 |
| 対象支出 | 通勤費/職務上の旅費(R2～)/転居費/研修費/資格取得費/帰宅旅費/勤務必要経費 |
| 勤務必要経費上限 | 65万円（図書費/衣服費/交際費等） |
| 証明 | 給与支払者またはキャリアコンサルタントの証明が必要 |

出典（国税庁タックスアンサー全文読み取り）:
- 国税庁: https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1415.htm
- 「給与所得控除額の2分の1相当額を超えるとき」
- 「65万円を超える場合には、65万円までの支出に限ります」
