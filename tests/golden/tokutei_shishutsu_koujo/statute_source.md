# 特定支出控除 — 出典固定

**状態: VERIFIED（2026-06-21, 国税庁タックスアンサー全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 控除額 | 特定支出合計−給与所得控除額×1/2 |
| 対象支出 | 通勤費/転居費/研修費/資格取得費/帰宅旅費/勤務必要経費 |
| 勤務必要経費上限 | 65万円 |
