# 遺族厚生年金 — 出典固定

**状態: VERIFIED（2026-06-21, 日本年金機構ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 年金額 | 死亡した方の老齢厚生年金の報酬比例部分×3/4 |
| 被保険者期間300月未満 | 300月とみなして計算 |
| 中高齢寡婦加算 | 40歳～65歳の妻に635,500円/年 |
| 受給優先順位 | 子のある配偶者>子>子のない配偶者>父母>孫>祖父母 |
| 子のない妻30歳未満 | 5年間のみ |
| 子のない夫 | 55歳以上（受給開始60歳） |
