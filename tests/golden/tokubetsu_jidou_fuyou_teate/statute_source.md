# 特別児童扶養手当 — 出典固定

**状態: VERIFIED（2026-06-15）**

| 項目 | 確定値 |
|---|---|
| 支給額 | 1級: 月額55,350円、2級: 月額36,860円（R8年度） |
| 対象 | 20歳未満の障害児を養育する父母等。身体障害1-2級相当 or 知的障害相当 |
| 所得制限 | あり。本人: 扶養0人 4,596,000円、1人 4,976,000円、以降+380,000円 |
| 除外 | 児童が施設入所中、児童が障害年金受給中 |

出典:
- 厚生労働省: https://www.mhlw.go.jp/bunya/shougaihoken/jidou/huyou.html
- 特別児童扶養手当等の支給に関する法律 第3条

判定に使うaskable:
- `shogai_techo_child` (per_child): 子の障害者手帳
- `nenshu` / `shotoku_exact`: 所得
- `fuyou_ninzu`: 扶養人数

限度額式: L = 4,596,000 + 380,000 * N（本人所得）
v1対象手帳: shintai_1→1級(55,350), shintai_2→2級(36,860), ryoiku→1級(55,350)
