# 足立区就学援助 — 出典固定

**状態: VERIFIED（2026-06-20, 公式ページ直接読み取り）**

| 項目 | 確定値 |
|---|---|
| 対象 | 区内在住+小中学校在籍の児童生徒の保護者 |
| 条件 | 生活保護/保護廃止/児童扶養手当受給/所得基準未満 |
| 金額 | 費目別（学用品費・給食費等）。令和8年度支給明細は7月上旬公開予定 |
| 参考（大田区公式） | 学用品費 月1,080〜1,720円、給食費 月4,100〜4,950円、新入学57,060円 |
| 注意 | 足立区は令和5年10月から区立小学校の給食費無償化済み |
| v1判定 | hikazei（非課税世帯）で近似。条文は非課税に限定していない |

出典（公式ページ直接読み取り）:
- 足立区公式: https://www.city.adachi.tokyo.jp/gakumu/k-kyoiku/shochu/tetsuzuki-shugaku.html
- 「学用品費等の支払いにお困りの保護者の方に対して、その費用の一部を援助する制度」
- 「令和８年度就学援助費支給明細表は７月上旬にお知らせする予定」（金額未公開）
- 対象: 「生活保護」「児童扶養手当受給」「所得基準未満」等

ルールの条文対応:
- school_age(6-15): 「小・中学校等に在籍する児童・生徒」に対応 ✓
- hikazei: 所得基準の近似（条文は非課税に限定していないが最も該当しやすい層）△
- kubun(shugaku_enjo): 金額が費目別で固定額表現不可のためin_kind扱い ✓
