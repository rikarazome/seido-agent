# 児童手当 — 条文ソース（出典固定）

**状態: VERIFIED（2026-06-11、一次情報で検証済み）**

| 項目 | 確定値 | 根拠 |
|---|---|---|
| 支給対象 | 18歳に達する日以後の最初の3月31日まで | 児童手当法3条（「児童」の定義）・4条1項 |
| 月額（3歳未満） | 第1・2子 15,000円 / 第3子以降 30,000円 | 法6条1項 |
| 月額（3歳〜18歳年度末） | 第1・2子 10,000円 / 第3子以降 30,000円 | 法6条1項 |
| 第3子カウント | 22歳に達する日以後の最初の3月31日までの子のうち、監護相当・生計費負担のあるものを年長から数える | 法3条3項（兄姉等の定義） |
| 所得制限 | 撤廃（2024-10施行） | 子ども・子育て支援法等改正法（令和6年法律47号）12条による法5条改正 |

注: 3歳未満の第3子以降も30,000円（15,000円ではない）。
