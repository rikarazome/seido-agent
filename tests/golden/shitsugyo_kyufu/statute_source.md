# 雇用保険基本手当（失業給付）— 出典固定

**状態: VERIFIED（2026-06-22, ハローワークページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 基本手当日額 | 賃金日額×50%～80%（60-64歳は45～80%） |
| 日額上限（R7.8.1） | 30歳未満7,255円 / 30-45歳8,055円 / 45-60歳8,870円 / 60-65歳7,623円 |
| 所定給付日数 | 年齢/被保険者期間/離職理由で90日～360日 |
| 受給要件 | 離職前2年間に被保険者期間12か月以上（特定受給資格者は1年間に6か月以上） |
| 受給期間 | 原則離職翌日から1年間 |
| 受講手当 | 日額500円（上限20,000円） |
| 通所手当 | 最高月42,500円 |
| 寄宿手当 | 月10,700円 |
| 高年齢求職者給付 | 1年以上50日分、1年未満30日分 |
