# 心身障害者医療費助成（東京都マル障） — 出典固定

**状態: VERIFIED（2026-06-15）**

| 項目 | 確定値 |
|---|---|
| 助成内容 | 医療費の自己負担分を助成（現物給付）。住民税非課税者は自己負担なし、課税者は1割負担 |
| 対象 | 身体障害者手帳1級・2級、愛の手帳（療育手帳）1度・2度、精神障害者保健福祉手帳1級 |
| 所得制限 | あり。本人所得: 扶養0人 3,604,000円、1人 3,984,000円、以降+380,000円 |
| 除外 | 65歳以上で新規取得（後期高齢者医療でカバー）、生活保護受給中 |

出典:
- 東京都福祉局: https://www.fukushi.metro.tokyo.lg.jp/iryo/josei/marusyou.html

判定に使うaskable:
- `shogai_techo`: 障害者手帳の種類+等級（enum）
- `nenshu` / `shotoku_exact`: 所得（ハイブリッド方式）
- `fuyou_ninzu`: 扶養人数
- `seikatsu_hogo`: 生活保護受給中（排他条件）

限度額式: L = 3,604,000 + 380,000 * N

対象手帳の判定:
- shintai_1, shintai_2 → 対象
- ryoiku → 対象（1度・2度。v1では療育手帳=対象と簡略化）
- seishin_1 → 対象
- shintai_3, seishin_2 → 対象外
- false（手帳なし）→ 対象外
