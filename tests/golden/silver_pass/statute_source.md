# 東京都シルバーパス — 出典固定

**状態: VERIFIED（2026-06-22, 公式サイト全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 対象 | 都内在住70歳以上（寝たきり除く） |
| 1,000円パス | 住民税非課税 or 合計所得135万円以下 |
| 12,000円パス | 上記以外（R8.4以降新規は6,000円に引下げ） |
| 有効期間 | 10月1日～翌年9月30日 |
| 利用可能 | 都営バス/地下鉄/都電/日暮里舎人ライナー + 民営バス |
| R8.10 | ICカード（PASMO）に移行 |
