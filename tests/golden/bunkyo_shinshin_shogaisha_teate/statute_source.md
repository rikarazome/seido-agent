# 文京区心身障害者等福祉手当 — 出典固定

**状態: VERIFIED（2026-06-20, 公式ページ直接読み取り）**

| 項目 | 確定値 |
|---|---|
| 対象者(1) 身体1-2/愛の手帳1-3/脳性麻痺/進行性筋萎縮 | 月額15,500円 |
| 対象者(2) 身体3/愛の手帳4 | 月額13,500円 |
| 対象者(3) 難病 | 月額15,500円 |
| 精神障害 | 別制度（精神障害者福祉手当）で対応 |
| 65歳以上 | 新規申請不可 |
| 所得制限 | あり |

- 文京区公式: https://www.city.bunkyo.lg.jp/b018/p003411.html

- 「対象者（2）月額13,500円 身体障害者手帳3級 愛の手帳4度」
- 「精神障害者保健福祉手帳をお持ちの方は、精神障害者福祉手当が対象」
