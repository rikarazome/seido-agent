# 青色申告特別控除 — 出典固定

**状態: VERIFIED（2026-06-21, 国税庁タックスアンサー全文読み取り + page_snapshot保存）**

| 記帳方式 | 控除額 |
|---|---|
| 複式簿記 + 電子申告/電子帳簿 | 最高65万円 |
| 複式簿記 | 最高55万円 |
| 簡易な記帳 | 最高10万円 |

| 項目 | 確定値 |
|---|---|
| 対象 | 不動産所得・事業所得・山林所得がある方 |
| 専従者給与 | 適正額を必要経費に算入可 |
| 純損失繰越 | 3年間（特定非常災害5年間） |
| 純損失繰戻 | 前年分の所得税還付 |
| 貸倒引当金 | 5.5%（金融業3.3%） |
