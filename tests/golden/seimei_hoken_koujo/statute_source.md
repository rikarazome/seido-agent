# 生命保険料控除 — 出典固定

**状態: VERIFIED（2026-06-21, 国税庁タックスアンサー全文読み取り + page_snapshot保存）**

| 新契約（H24.1.1以後） | 支払保険料等 | 控除額 |
|---|---|---|
| | 20,000円以下 | 全額 |
| | 20,000超～40,000以下 | ×1/2+10,000 |
| | 40,000超～80,000以下 | ×1/4+20,000 |
| | 80,000円超 | 一律40,000円 |

| 旧契約（H23.12.31以前） | 支払保険料等 | 控除額 |
|---|---|---|
| | 25,000円以下 | 全額 |
| | 25,000超～50,000以下 | ×1/2+12,500 |
| | 50,000超～100,000以下 | ×1/4+25,000 |
| | 100,000円超 | 一律50,000円 |

合計控除上限: 120,000円
