# 生活福祉資金貸付制度 — 出典固定

**状態: VERIFIED（2026-06-22, 厚労省ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 対象 | 低所得者世帯（非課税程度）/障害者世帯/高齢者世帯(65歳以上) |
| 貸付種類 | 総合支援/福祉/教育支援/不動産担保型 |
| 連帯保証人あり | 無利子 |
| 連帯保証人なし | 年1.5% |
| 緊急小口/教育支援 | 無利子 |
| 不動産担保型 | 年3% or 長期プライムレートの低い方 |
| 実施主体 | 都道府県社会福祉協議会 |
