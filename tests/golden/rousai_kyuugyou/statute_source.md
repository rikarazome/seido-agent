# 休業（補償）等給付 — 出典固定

**状態: VERIFIED（2026-06-22, WebSearch調査。具体額はPDFパンフレットに記載）**

| 項目 | 確定値 |
|---|---|
| 支給額 | 給付基礎日額の60%×休業日数 + 特別支給金20% |
| 要件 | 業務上/通勤による傷病で労務不能+賃金未受領 |
| 待期 | 3日間（4日目から支給） |
