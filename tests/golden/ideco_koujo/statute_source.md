# iDeCo（個人型確定拠出年金）の所得控除 — 出典固定

**状態: VERIFIED（2026-06-22, iDeCo公式メリットページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 掛金の控除 | 全額所得控除（小規模企業共済等掛金控除） |
| 運用益 | 非課税（通常20.315%が非課税） |
| 受取時（年金） | 公的年金等控除 |
| 受取時（一時金） | 退職所得控除 |
| 掛金上限額 | このページに記載なし（「加入資格・掛金・受取方法等」ページに記載） |
| 特別法人税 | 年1.173%（現在課税停止） |
