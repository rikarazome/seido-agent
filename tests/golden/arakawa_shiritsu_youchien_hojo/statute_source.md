# 荒川区私立幼稚園等園児保護者補助金 — 出典固定

**状態: VERIFIED（2026-06-20, 公式ページ直接読み取り）**

| 項目 | 確定値 |
|---|---|
| 対象 | 3-5歳、区内在住、私立幼稚園等在園 |
| 入園料補助 | 上限70,000円/年 |
| 保育料補助 | 所得に応じた額（区市町村民税所得割額で決定） |
| 給食費補助 | 上限7,500円/月 |
| 所得制限 | なし（補助額が所得で変動） |

出典（公式ページ直接読み取り）:
- 荒川区公式: https://www.city.arakawa.tokyo.jp/a035/kosodate/hoikuen/hojo.html
- 「入園料や保育料等、給食費、預かり保育料に対して補助」
- 「補助上限額 70,000円（年額）」
- 「補助上限額 7,500円（月額）（牛乳代、おやつ代含む）」

ルールの条文対応:
- age_nendo_matsu 3-5: ✓
- kubun(youchien_hojo): 金額が所得で変動するためin_kind ✓
