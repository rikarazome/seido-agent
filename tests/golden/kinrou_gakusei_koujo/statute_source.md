# 勤労学生控除 — 出典固定

**状態: VERIFIED（2026-06-21, 国税庁タックスアンサー全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 控除額 | 27万円（固定） |
| 所得要件 | 合計所得75万円以下（R7分から85万円以下） |
| 勤労外所得 | 10万円以下 |
| 給与収入換算 | 130万円以下 |
| 対象学校 | 小中高大、専修学校、職業訓練校等 |
