# 補装具費支給制度 — 出典固定

**状態: VERIFIED（2026-06-22, 厚労省ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 利用者負担 | 原則定率1割 |
| 生活保護世帯 | 0円 |
| 低所得（非課税世帯） | 0円 |
| 一般（課税世帯） | 37,200円/月上限 |
| 対象外 | 所得割46万円以上 |
| 対象者 | 障害者、障害児、難病患者等 |
| 実施主体 | 市町村 |
| 費用負担 | 国50%/都道府県25%/市町村25% |
| 種目 | 義肢、装具、車椅子、補聴器、人工内耳等 |
| 根拠 | 障害者総合支援法76条 |
