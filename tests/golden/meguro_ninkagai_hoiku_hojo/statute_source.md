# 目黒区認可外保育施設保育料助成制度 — 出典固定

**状態: VERIFIED（2026-06-21, 公式ページ全文読み取り + page_snapshot保存）**

| 区分 | 助成金額 |
|---|---|
| 0-2歳 課税 第1子 | 80,000円（利用者支援40K+第1子支援40K） |
| 0-2歳 課税 第2子以降 | 80,000円（利用者支援40K+多子支援40K） |
| 0-2歳 非課税 第1子 | 38,000円（+施設等利用費42K=合計80K） |
| 3-5歳 | 40,000円（+施設等利用費37K=合計77K） |

条件:
- 月160時間以上の保育委託契約
- 保育の必要性の認定（求職中は対象外）
- 認可保育所等・幼稚園に非在籍
- 対象施設: 認証保育所、家庭的保育、指導監督基準証明書交付施設
