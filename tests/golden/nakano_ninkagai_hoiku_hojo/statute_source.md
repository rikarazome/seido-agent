# 中野区認証保育所等保護者補助金 — 出典固定

**状態: VERIFIED（2026-06-22, 中野区公式ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 補助上限 | 月額70,000円（月ぎめ基本保育料との低い方） |
| 対象 | 就労等の事由で認証保育所/認可外保育施設利用者 |
| 方式 | 後払い（保育料納入確認後に交付） |
| 対象外 | 入園料、行事費等 |
