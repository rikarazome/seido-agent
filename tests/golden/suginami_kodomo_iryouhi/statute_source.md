# 杉並区子ども医療費助成 — 出典固定

**状態: VERIFIED（2026-06-21, 公式ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 対象年齢 | 出生から18歳到達後最初の3月31日まで |
| 助成内容 | 保険診療の自己負担分を助成（in_kind） |
| 要件 | 杉並区住民登録 + 日本の医療保険加入 |
| 所得制限 | なし（ページに記載なし） |

| 注意 | 入院時食事療養標準負担額は対象外 |
