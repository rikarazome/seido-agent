# 北区子ども医療費助成 — 出典固定

**状態: VERIFIED（2026-06-21, 公式ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 対象年齢 | 18歳到達後最初の3月31日まで |
| 助成内容 | 保険診療の自己負担額を助成（in_kind） |
| 要件 | 北区住民登録 + 日本の公的健康保険加入 |
| 所得制限 | なし（「保護者等の所得制限はありません」と明記） |
| 除外 | 生活保護、児童福祉施設入所、里親委託 |
| 注意 | 入院時食事療養費は対象外 |
