# 江戸川区乳児養育手当 — 出典固定

**状態: VERIFIED（2026-06-22, 江戸川区公式ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 支給額 | 月額13,000円 |
| 対象 | 0歳児を養育している方（最大12回支給） |
| 要件 | 乳児・保護者ともに江戸川区在住 |
| 生活保護 | 受けていないこと |
| 乳児院 | 預けていないこと |
| 所得制限 | なし |
| 申請期限 | 満1歳の誕生日の前日まで |
| 課税 | 雑所得に該当（要申告の場合あり） |
| 支給日 | 毎月10日 |
