# 難病医療費助成 — 出典固定

**状態: VERIFIED（2026-06-15）**

| 項目 | 確定値 |
|---|---|
| 助成内容 | 指定難病の医療費自己負担を軽減（所得に応じた月額上限あり。最大30,000円/月） |
| 対象 | 指定難病（341疾病）の認定を受けた患者 |
| 所得制限 | **なし**（認定が前提。自己負担上限額は所得に応じるが、制度の対象判定自体に所得制限はない） |
| 除外 | 生活保護受給中は自己負担0円（制度自体は対象だが、実質的に生活保護でカバー） |

出典:
- 厚生労働省: https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/kenkou/nanbyou/
- 難病の患者に対する医療等に関する法律 第5条

判定に使うaskable:
- `nanbyo_nintei`: 指定難病認定（boolean）

注: 本制度は認定の有無のみで判定。認定プロセス（診断書→都道府県審査）は申請手続きの案内で補足。
v1では自己負担上限額の算出は省略し、「医療費負担が軽減されます」とin_kindで案内。
