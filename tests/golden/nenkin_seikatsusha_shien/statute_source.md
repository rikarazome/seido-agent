# 年金生活者支援給付金 — 出典固定

**状態: VERIFIED（2026-06-22, 厚労省特設サイト全文読み取り + page_snapshot保存）**

| 種類 | 給付額（R8.4時点） |
|---|---|
| 老齢（納付済期間） | 5,620円×納付済月数/480月 |
| 老齢（免除期間） | 11,768円×免除月数/480月 |
| 障害2級 | 月5,620円 |
| 障害1級 | 月7,025円 |
| 遺族 | 月5,620円（複数の子で均等割） |

| 支給要件 | 確定値 |
|---|---|
| 老齢 | 65歳以上、世帯全員非課税、年金+所得909,000円以下(S31.4.2以後) |
| 障害/遺族 | 所得4,794,000円以下 |
