# 足立区出産費助成事業 — 出典固定

**状態: VERIFIED（2026-06-22, 足立区公式ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 助成額 | 出産費用の自己負担分に対し子ども1人につき上限100,000円 |
| 自己負担 | 出産費用−出産育児一時金等 |
| 対象 | 出生日以前から足立区在住＋申請日時点で1年以上居住 |
| 生活保護 | 対象外 |
| 申請期限 | 出産日から1年以内 |
| 流産・死産 | 妊娠85日以上は対象 |
