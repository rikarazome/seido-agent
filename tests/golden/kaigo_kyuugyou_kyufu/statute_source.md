# 介護休業給付金 — 出典固定

**状態: VERIFIED（2026-06-22, 厚労省Q&Aページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 支給額 | 休業開始時賃金日額×支給日数×67% |
| 限度 | 同一家族について93日を限度に3回まで |
| 対象家族 | 配偶者/父母/子/配偶者の父母/祖父母/兄弟姉妹/孫 |
| 要件 | 休業開始前2年間に被保険者期間12か月以上 |
| 就労制限 | 1支給単位期間に10日以下 |
| 課税 | 非課税 |

支給額例（賃金の支払いがない場合）:
- 月15万→月10万程度、月20万→月13.4万程度、月30万→月20.1万程度
