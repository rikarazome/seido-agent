# 教育訓練給付金 — 出典固定

**状態: VERIFIED（2026-06-21, 厚労省ページ全文読み取り + page_snapshot保存）**

| 訓練種類 | 給付率 | 上限 |
|---|---|---|
| 専門実践（受講中） | 50% | 年間40万円 |
| 専門実践（資格+就職） | 70% | 年間56万円 |
| 専門実践（賃金5%↑） | 80% | 年間64万円 |
| 特定一般 | 40% | 20万円 |
| 特定一般（資格+就職） | 50% | 25万円 |
| 一般 | 20% | 10万円 |
