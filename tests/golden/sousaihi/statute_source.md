# 葬祭費（国民健康保険）— 出典固定

**状態: VERIFIED（2026-06-22, 練馬区公式ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 支給額 | 7万円（東京23区は一律7万円） |
| 対象 | 国保加入者が死亡→葬儀を行った方（喪主） |
| 申請期限 | 葬儀を行った日の翌日から2年間 |
| 社保との選択 | 社保に1年以上加入→退職後3か月以内死亡は選択可 |
| 75歳以上 | 後期高齢者医療制度から支給 |
