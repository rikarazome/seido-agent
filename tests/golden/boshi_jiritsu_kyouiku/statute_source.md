# ひとり親家庭自立支援教育訓練給付金 — 出典固定

**状態: VERIFIED（2026-06-22, こども家庭庁ページ全文読み取り + page_snapshot保存）**

| 講座種別 | 給付率 | 上限 |
|---|---|---|
| 一般/特定一般教育訓練 | 60% | 最大20万円（下限12,001円） |
| 専門実践教育訓練 | 60% | 修学年数×40万円（最大160万円） |
| 専門実践（資格取得+就職） | 85% | 修業年数×60万円（最大240万円） |

| 項目 | 確定値 |
|---|---|
| 対象 | 母子家庭の母/父子家庭の父で20歳未満の児童を扶養 |
| 児童20歳到達後 | 受講修了まで対象継続 |
| 要件 | 母子・父子自立支援プログラム策定を受けていること |
| 事前手続 | 受講前に都道府県等の講座指定が必要 |
| 雇用保険との関係 | 教育訓練給付を受けられる人は差額支給 |
