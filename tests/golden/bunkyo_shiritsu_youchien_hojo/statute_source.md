# 文京区私立幼稚園補助 — 出典固定

**状態: VERIFIED（2026-06-21, 公式ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 対象 | 3-5歳（満3歳含む）、区内在住、私立幼稚園在園（新制度移行園除く） |
| 入園料 | 上限70,000円（所得制限なし、園児1人1度まで） |
| 基本利用料 | 月額35,000円～39,400円（所得階層で変動） |
| 預かり保育料 | 月額11,300円/16,300円上限（R8.10～ 12,300/17,700円） |
| 所得制限 | なし（補助額は所得で変動） |

出典（公式ページ全文読み取り）:
- 文京区公式: https://www.city.bunkyo.lg.jp/b023/p001707.html
- 「入園料補助金 園児一人につき上限70,000円」
- 金額テーブル: 施設等利用費25,700円+保護者負担軽減補助9,300円=35,000円（階層3以上）
