# 出産・子育て応援交付金 — 出典固定

**状態: VERIFIED（2026-06-15）**

| 項目 | 確定値 |
|---|---|
| 支給額 | 妊娠届出時5万円（妊娠応援ギフト）+ 出生届出後5万円（子育て応援ギフト）= 計10万円 |
| 対象 | 妊娠届出をした妊婦 + 出生した児童の養育者。自治体の面談を受けること |
| 所得制限 | **なし** |
| 実施主体 | 市区町村（国の補助事業、2023年1月〜） |
| 形態 | 自治体によりクーポン/現金/電子マネー等。本プロダクトでは金額のみ表示（100,000円） |

出典:
- こども家庭庁: https://www.cfa.go.jp/policies/shussan-kosodate/
- 児童福祉法の一部を改正する法律（令和4年法律第104号）

判定に使うaskable:
- `ninshin`: 妊娠中か（boolean）— 妊娠応援ギフトの受給資格

注: 本制度は妊娠届出と出生届出の2段階で支給。v1では妊娠中=true→100,000円の一括表示とする
（出産済みの場合は既に支給済みの可能性が高く、対象者は現在妊娠中の人がメイン）。
面談要件は判定対象外（申請手続きの案内で補足）。
