# 配偶者控除 — 出典固定

**状態: VERIFIED（2026-06-21, 国税庁タックスアンサー全文読み取り + page_snapshot保存）**

| 納税者の合計所得 | 一般 | 老人(70歳以上) |
|---|---|---|
| 900万円以下 | 38万円 | 48万円 |
| 900万超950万以下 | 26万円 | 32万円 |
| 950万超1,000万以下 | 13万円 | 16万円 |
| 1,000万円超 | 控除なし | 控除なし |

| 項目 | 確定値 |
|---|---|
| 配偶者の所得要件（R7分～） | 合計所得58万円以下（給与のみ123万円以下） |
| 配偶者特別控除 | 配偶者の合計所得58万超133万以下で最高38万円 |
| 障害者の場合 | 障害者控除(27/40/75万円)を併用可 |
