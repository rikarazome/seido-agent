# 障害（補償）等給付 — 出典固定

**状態: VERIFIED（2026-06-22, WebSearch調査。具体額はPDFパンフレットに記載）**

| 項目 | 確定値 |
|---|---|
| 1-7級 | 障害（補償）等年金（等級に応じた日数分） |
| 8-14級 | 障害（補償）等一時金（等級に応じた日数分） |
| 要件 | 業務上/通勤による傷病が治ゆ後に障害が残った場合 |
