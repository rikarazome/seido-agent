# 葛飾区認可外保育施設利用料助成金 — 出典固定

**状態: VERIFIED（2026-06-22, 葛飾区公式ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 助成上限 | 月額80,000円 |
| 対象施設 | 指導監督基準証明書交付の認可外（認証一時利用含む） |
| 対象経費 | 保育料＋食材料費（R7.9から食材料費含む） |
| 120時間以上契約 | 施設補助 |
| 120時間未満 | 保護者補助 |
| 0-2歳課税 | 保育給付認定(2号/3号)必要 |
| 0-2歳非課税/3-5歳 | 施設等利用給付認定(新2号/新3号)必要 |
