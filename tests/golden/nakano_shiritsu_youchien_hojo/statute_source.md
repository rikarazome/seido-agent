# 中野区私立幼稚園等補助金 — 出典固定

**状態: VERIFIED（2026-06-22, 中野区公式ページ全文読み取り + page_snapshot保存）**

| 補助の種類 | 金額 |
|---|---|
| 入園料補助 | 60,000円上限（1回限り） |
| 保育料補助（私学助成園） | 月37,700円上限（施設等利用費25,700+保護者補助12,000） |
| 保育料補助（幼稚園類似） | 月37,700円上限 |
| 保育料補助（施設型給付園） | 特定負担額に月6,200円上限 |
| 預かり保育補助 | 月11,300円上限（満3歳16,300円） |
| 副食費補助 | 月4,900円上限 |
