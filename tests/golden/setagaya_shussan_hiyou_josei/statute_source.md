# 世田谷区出産費助成制度 — 出典固定

**状態: VERIFIED（2026-06-22, 世田谷区公式ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 助成額 | 出産児1人につき50,000円（固定額） |
| 対象 | 出産日時点で世田谷区内に住所がある方 |
| 申請期限 | 出産日から1年以内 |
| 流産・死産 | 妊娠85日以上は対象 |
| 課税 | 一時所得に該当 |
