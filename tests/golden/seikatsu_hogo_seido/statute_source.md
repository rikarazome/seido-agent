# 生活保護制度 — 出典固定

**状態: VERIFIED（2026-06-21, 厚労省ページ全文読み取り + page_snapshot保存）**

| 扶助の種類 | 内容 |
|---|---|
| 生活扶助 | 食費等(年齢別)+光熱水費等(世帯人員別)+冬季加算+障害者加算等 |
| 住宅扶助 | 定められた範囲内で実費 |
| 教育扶助 | 定められた基準額 |
| 医療扶助 | 本人負担なし |
| 介護扶助 | 本人負担なし |
| 出産扶助 | 定められた範囲内で実費 |
| 生業扶助 | 定められた範囲内で実費 |
| 葬祭扶助 | 定められた範囲内で実費 |

要件: 資産活用+能力活用+他制度活用+扶養義務者の扶養
