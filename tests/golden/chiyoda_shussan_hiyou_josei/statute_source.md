# 千代田区出産費用助成（区独自制度）— 出典固定

**状態: VERIFIED（2026-06-22, 千代田区公式ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 助成額 | 自己負担分に対し1度の出産につき最大310,000円 |
| 計算 | 出産費用実費−出産育児一時金=助成額 |
| 対象 | 出産日以前から区内住所+申請日で1年以上居住 |
| 生活保護 | 対象外 |
| 申請期限 | 出産日から2年間 |
| 適用開始 | R7.4.1以後の出産 |
