# 地震保険料控除 — 出典固定

**状態: VERIFIED（2026-06-21, 国税庁タックスアンサー全文読み取り + page_snapshot保存）**

| 区分 | 年間支払保険料 | 控除額 |
|---|---|---|
| 地震保険料 | 50,000円以下 | 全額 |
| 地震保険料 | 50,000円超 | 一律50,000円 |
| 旧長期損害保険料 | 10,000円以下 | 全額 |
| 旧長期損害保険料 | 10,000超～20,000以下 | 支払額×1/2+5,000円 |
| 旧長期損害保険料 | 20,000円超 | 15,000円 |
| 両方ある場合 | — | 合計（最高50,000円） |
