# 退職所得控除 — 出典固定

**状態: VERIFIED（2026-06-22, 国税庁タックスアンサー全文読み取り + page_snapshot保存）**

| 勤続年数 | 退職所得控除額 |
|---|---|
| 20年以下 | 40万円×A（最低80万円） |
| 20年超 | 800万円+70万円×(A−20年) |

退職所得 = (収入金額 − 退職所得控除額) × 1/2

| 特例 | 内容 |
|---|---|
| 障害退職 | 控除額+100万円 |
| 特定役員退職手当等（役員勤続5年以下） | 1/2計算なし |
| 短期退職手当等（勤続5年以下・役員等以外） | 300万超部分は1/2計算なし |
