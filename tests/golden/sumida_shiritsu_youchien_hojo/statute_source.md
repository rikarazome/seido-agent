# 墨田区私立幼稚園等補助金 — 出典固定

**状態: VERIFIED（2026-06-22, 墨田区公式ページ全文読み取り + page_snapshot保存）**

| 補助（私学助成園） | 金額 |
|---|---|
| 入園料補助 | 70,000円上限（1回限り） |
| 保育料補助 | 月33,000円まで代理受領+超過分は償還払い |
| 給食費等補助 | 月3,750円 |
| 副食費相当額 | 月5,100円上限（所得割77,100円以下or第3子以降） |
