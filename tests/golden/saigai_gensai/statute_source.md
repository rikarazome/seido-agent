# 災害減免法・雑損控除 — 出典固定

**状態: VERIFIED（2026-06-21, 国税庁タックスアンサー全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 雑損控除(1) | (損害金額+災害関連支出−保険金等)−総所得金額等×10% |
| 雑損控除(2) | (災害関連支出−保険金等)−5万円 |
| 控除額 | 上記いずれか多い方 |
| 対象 | 災害/盗難/横領（詐欺・恐喝は対象外） |
| 繰越 | 3年間（特定非常災害5年間） |
| 災害減免法 | 所得1,000万以下で選択可 |
