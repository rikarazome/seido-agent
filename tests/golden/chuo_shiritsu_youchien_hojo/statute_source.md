# 中央区幼稚園等の保護者向け補助金 — 出典固定

**状態: VERIFIED（2026-06-21, 公式ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 対象 | 満3歳～5歳、区内在住、私立幼稚園等在園 |
| 施設等利用費 | 未移行園 月25,700円上限、国立附属 月8,700円 |
| 保護者負担軽減 | 月1,800～6,200円（所得階層で変動） |
| 預かり保育 | 2号月11,300円、3号月16,300円、0-2歳月42,000円 |
| 入園料 | ページに記載なし |
