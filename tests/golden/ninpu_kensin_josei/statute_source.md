# 妊婦健康診査の公費助成（14回分）

- 母子保健法13条: https://laws.e-gov.go.jp/law/340AC0000000141/
- 厚労省 妊婦健診リーフレット: https://www.mhlw.go.jp/bunya/kodomo/boshi-hoken13/

## 制度概要（母子保健法13条・厚労省公式より）
- 妊婦に対し14回程度の健康診査を市区町村が実施
- 全市区町村で14回以上の公費負担を実施（2024年4月時点で全国平均14.04回）
- 妊娠届出後に母子健康手帳と受診票が交付される
- 所得制限なし

## 現ルールでの判定
- ninshin=true（妊娠中）で判定。母子保健法13条の対象要件と直接対応。
