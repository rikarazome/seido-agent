# 練馬区認可外保育施設保育料補助 — 出典固定

**状態: VERIFIED（2026-06-22, 練馬区公式ページ全文読み取り + page_snapshot保存）**

| 助成の種類 | 0-2歳非課税 | 0-2歳課税 | 3-5歳 |
|---|---|---|---|
| 施設等利用費 | 月42,000円 | 対象外 | 月37,000円 |
| 保育料補助金(R7.9～) | 38,000円 | 80,000円 | 40,000円 |
| 合計 | 80,000円 | 80,000円 | 77,000円 |

| 項目 | 確定値 |
|---|---|
| 契約要件 | 月160時間以上月ぎめ |
| 対象施設 | 認証保育所 or 指導監督基準証明書発行の認可外 |
| 対象外 | 給食費、実費分 |
