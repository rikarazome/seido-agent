# NHK受信料の免除 — 出典固定

**状態: VERIFIED（2026-06-22, NHK受信料の窓口ページ全文読み取り + page_snapshot保存）**

| 区分 | 条件 |
|---|---|
| 全額免除 | 障害者が世帯構成員＋世帯全員が市町村民税非課税 |
| 半額免除 | 視覚/聴覚障害者が世帯主、または重度障害者が世帯主 |
| 奨学生等免除 | 経済的理由の奨学金受給＋別住居の学生 |

| 項目 | 確定値 |
|---|---|
| 障害の種類 | 身体/知的/精神いずれも対象 |
| 重度の定義 | 特別障害者（所得税/地方税の控除対象） |
| 手続き | 免除申請書→自治体で証明→NHKに提出 |
| 免除開始 | NHK受理月から |

- NHK: https://www.nhk-cs.jp/jushinryo/menjo/qa.html

- 「重度の障害者が世帯主で受信契約者の場合は半額免除」
