# 住宅ローン減税（住宅借入金等特別控除）— 出典固定

**状態: VERIFIED（2026-06-21, 国税庁タックスアンサー全文読み取り + page_snapshot保存）**

| 住宅区分（R6-R7居住） | 控除限度額/年 | 控除期間 |
|---|---|---|
| 認定住宅 | 31.5万円（特例対象個人35万円） | 13年 |
| ZEH水準省エネ | 24.5万円（特例対象個人31.5万円） | 13年 |
| 省エネ基準適合 | 21万円（特例対象個人28万円） | 13年 |
| その他住宅 | 原則0（経過措置14万円/10年） | — |

| 項目 | 確定値 |
|---|---|
| 控除率 | 年末残高等×0.7% |
| 床面積要件 | 50㎡以上（特例40㎡以上） |
| 所得要件 | 合計所得2,000万円以下（特例1,000万円以下） |
| 返済要件 | 10年以上分割返済 |
| 手続き | 初年度確定申告、2年目以降年末調整 |
