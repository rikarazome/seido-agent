# 障害児福祉手当 — 出典固定

**状態: VERIFIED（2026-06-15）**

| 項目 | 確定値 |
|---|---|
| 支給額 | 月額15,690円（R8年度） |
| 対象 | 20歳未満で重度の障害があり、日常生活に常時介護を必要とする児童 |
| 所得制限 | あり。本人(扶養義務者): 扶養0人 4,596,000円、以降+380,000円 |
| 除外 | 施設入所中、障害年金受給中 |

出典:
- 厚生労働省: https://www.mhlw.go.jp/bunya/shougaihoken/jidou/tokubetsu.html
- 特別児童扶養手当等の支給に関する法律 第17条

判定に使うaskable:
- `shogai_techo_child` (per_child): 子の障害者手帳
- `nenshu` / `shotoku_exact`: 所得（扶養義務者の所得）
- `fuyou_ninzu`: 扶養人数

限度額式: L = 4,596,000 + 380,000 * N（扶養義務者所得）

v1簡略化: 「重度障害+常時介護」をshintai_1で代理判定。
実際は重度の判定（身体1級の一部+重複障害等）は自治体の認定が必要。
shintai_1を目安に「該当の可能性あり（自治体で認定が必要）」として案内。
