# 傷病手当金 — 出典固定

**状態: VERIFIED（2026-06-22, 協会けんぽページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 支給額 | 支給開始日以前12か月間の各標準報酬月額平均÷30×2/3 |
| 12か月未満の場合 | ア各月平均 or イ全被保険者平均(R7.4～32万円)の低い方 |
| 支給期間 | 通算1年6か月 |
| 待期 | 連続3日間（4日目から支給） |
| 要件 | 業務外の病気/けが、労務不能、4日以上休業、給与支払なし |
| 退職後継続 | 資格喪失前日まで1年以上被保険者+資格喪失時に受給中 |
| 出産手当金との併給 | 出産手当金優先（差額支給あり） |
