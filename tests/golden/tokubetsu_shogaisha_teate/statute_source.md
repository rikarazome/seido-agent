# 特別障害者手当 — 出典固定

**状態: VERIFIED（2026-06-15）**

| 項目 | 確定値 |
|---|---|
| 支給額 | 月額28,840円（R8年度。毎年度改定） |
| 対象 | 20歳以上で著しく重度の障害（身体1級の一部+重複障害等）により常時特別な介護が必要 |
| 所得制限 | あり。本人: 扶養0人 3,604,000円、以降+380,000円。配偶者・扶養義務者: 6,287,000円〜 |
| 除外 | 施設入所中、病院等に3か月以上入院 |
| 障害要件 | v1簡略化: 身体1級（shintai_1）を対象とする。実際は重複障害等の詳細判定が必要だが、窓口案内として身体1級を目安にする |

出典:
- 厚生労働省: https://www.mhlw.go.jp/bunya/shougaihoken/jidou/tokubetsu.html
- 特別児童扶養手当等の支給に関する法律 第26条の5

判定に使うaskable:
- `shogai_techo`: 障害者手帳（shintai_1のみ対象。v1簡略化）
- `nenshu` / `shotoku_exact`: 所得
- `fuyou_ninzu`: 扶養人数
- `seikatsu_hogo`: 生活保護受給中（排他ではないが施設入所との関連で確認）

限度額式: L = 3,604,000 + 380,000 * N（本人所得。配偶者・扶養義務者の限度額はv1では省略）

注: 本制度は実際には「著しく重度の障害」の判定が複雑。v1では身体1級を目安として案内し、
「窓口で詳細な判定を受けてください」と併記する。
