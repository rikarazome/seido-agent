# 特別障害者手当 — 出典固定

**状態: VERIFIED（2026-06-19, R8年度改定反映）**

| 項目 | 確定値 |
|---|---|
| 支給額 | 月額30,450円（令和8年4月1日〜） |
| 対象 | 20歳以上で著しく重度の障害（身体1級の一部+重複障害等）により常時特別な介護が必要 |
| 所得制限 | あり。本人: 扶養0人 3,661,000円、以降+380,000円。配偶者・扶養義務者: 6,287,000円〜 |
| 除外 | 施設入所中、病院等に3か月以上入院 |
| 障害要件 | v1簡略化: 身体1級（shintai_1）を対象とする |

出典（公式ページ直接読み取り）:
- 金額: 葛飾区公式 https://www.city.katsushika.lg.jp/kenkou/1000053/1002245/1039928/1039704.html
  「月額 30,450円（令和8年4月1日現在）」と明記
- 所得制限: 同ページ所得限度額表 扶養0人=3,661,000円、1人=4,041,000円（差380,000）
- 根拠法: 特別児童扶養手当等の支給に関する法律 第26条の5

判定に使うaskable:
- `shogai_techo`: 障害者手帳（shintai_1のみ対象。v1簡略化）
- `nenshu` / `shotoku_exact`: 所得
- `fuyou_ninzu`: 扶養人数
- `seikatsu_hogo`: 生活保護受給中

限度額式: L = 3,661,000 + 380,000 * N（本人所得）
