# 台東区就学援助 — 出典固定

**状態: VERIFIED（2026-06-21, 公式ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 対象 | 区内在住+国公立小中学校在籍+所得基準未満 |
| 費目 | 学用品費、新入学学用品費、通学服費、クラブ活動費等 |
| 注意 | 給食費・修学旅行費等は別事業で支援のため就学援助対象外 |
| 私立 | 対象外 |
