# NISA（少額投資非課税制度）— 出典固定

**状態: VERIFIED（2026-06-22, 金融庁NISA特設サイト全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 非課税対象 | 運用益（売却益・配当/分配金） |
| つみたて投資枠 | 年間120万円 |
| 成長投資枠 | 年間240万円 |
| 年間投資枠合計 | 360万円 |
| 非課税保有限度額 | 1,800万円（うち成長投資枠1,200万円上限） |
| 非課税保有期間 | 無期限 |
| 制度期間 | 恒久化（2024年1月～） |
| 対象 | 18歳以上、1人1口座 |
| 売却時 | 翌年以降、簿価分の非課税枠が復活 |
