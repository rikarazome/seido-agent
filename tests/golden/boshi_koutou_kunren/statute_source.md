# ひとり親家庭高等職業訓練促進給付金 — 出典固定

**状態: VERIFIED（2026-06-21, こども家庭庁ページ全文読み取り + page_snapshot保存）**

| 区分 | 非課税世帯 | 課税世帯 |
|---|---|---|
| 訓練期間中 | 月100,000円 | 月70,500円 |
| 最後の1年間 | +40,000円増額 | +40,000円増額 |
| 訓練修了後 | 50,000円 | 25,000円 |

| 項目 | 確定値 |
|---|---|
| 対象 | ひとり親（児童扶養手当受給相当、例:子1人で年収385万未満） |
| 期間要件 | 養成機関で6月以上修業 |
| 対象資格 | 看護師、保育士、介護福祉士等の国家資格+デジタル分野民間資格 |
| 継続給付 | 子が20歳到達後も引き続き扶養なら同等給付 |
