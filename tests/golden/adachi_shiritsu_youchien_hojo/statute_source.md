# 足立区私立幼稚園保護者補助金 — 出典固定

**状態: VERIFIED（2026-06-21, 公式ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 対象 | 3-5歳児（満3歳・2歳含む）、区内在住、私立幼稚園等在園 |
| 移行園 | 保育料25,700円/月（国無償化）+ 特定負担額9,300円/月 = 月35,000円 |
| 未移行園 | 保育料月額上限35,000円まで補助（国25,700+都区9,300） |
| 入園料 | 上限100,000円（1園児1回限り） |
| 給食費 | 上限7,500円/月 |
| 所得制限 | なし |
