# 障害基礎年金 — 出典固定

**状態: VERIFIED（2026-06-21, 日本年金機構ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 1級 | 老齢基礎年金額×1.25 + 子の加算 |
| 2級 | 老齢基礎年金額 + 子の加算 |
| 子の加算 | 1-2人目各243,800円、3人目以降各81,300円 |
| 要件 | 初診日に被保険者、保険料納付期間2/3以上等 |
