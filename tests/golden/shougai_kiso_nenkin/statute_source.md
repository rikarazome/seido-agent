# 障害基礎年金 — 出典固定

**状態: VERIFIED（2026-06-22, 日本年金機構ページ全文読み取り + page_snapshot保存）**

**注意: このスナップショットは障害年金の概要ページ。具体的な年金額は個別ページに記載。**

| 項目 | 確定値 |
|---|---|
| 障害基礎年金 | 1級・2級（年金額は個別ページに記載） |
| 障害厚生年金 | 1級・2級・3級 + 障害手当金 |
| 初診日が国民年金加入中 | 障害基礎年金 |
| 初診日が厚生年金加入中 | 障害厚生年金（+障害基礎年金） |
| 保険料納付要件 | 加入期間の2/3以上納付/免除 or 直近1年間未納なし |
| 20歳前の初診日 | 納付要件なし |
| 法定免除 | 障害基礎/厚生年金(1-2級)受給者は国民年金保険料免除 |
