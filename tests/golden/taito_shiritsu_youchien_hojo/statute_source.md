# 台東区私立幼稚園等保護者補助金 — 出典固定

**状態: VERIFIED（2026-06-22, 台東区公式ページ全文読み取り + page_snapshot保存）**

都の負担軽減補助金+区の保護者補助金の2本立て。所得割課税額と子の順位で金額が異なる。
例: 生活保護世帯 都6,200+区8,600=14,800円/月、所得割77,100円以下第1子 都1,800+区1,200=3,000円/月

| 項目 | 確定値 |
|---|---|
| 預かり保育補助（都） | 満3歳課税 月16,300円上限（450円×日数） |
| 3-5歳無償化給付 | 月12,300円上限 |
| 新制度移行園 | 本補助金の対象外 |
