## 所得の定義（施行令・平成14年厚労省通知）

`所得 = 給与所得控除後の額 +（養育費 × 0.8）− 80,000円（社会保険料相当） − 諸控除`
（給与・年金所得がある場合は合計から追加10万円控除の特例あり）

## 支給事由（法4条1項）と除外（法4条2項）

- 事由: 離婚 / 死亡 / 父母の重度障害 / 生死不明 / **1年以上の遺棄** / **1年以上の拘禁** / 未婚懐胎 / **DV保護命令** → questions.yaml の列挙に反映済み
- 除外: 国内非居住 / 里親委託 / 施設入所 / 父（母）と生計同一（障害時除く）/ **父（母）の配偶者（事実婚含む）に養育されているとき** ← 現ルールの jogai に対応
