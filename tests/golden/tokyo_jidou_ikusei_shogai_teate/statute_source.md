# Tokyo Child Development Allowance (Disability) -- source fixation

**VERIFIED (2026-06-15)**

| Item | Value |
|---|---|
| Amount | 15,500 JPY/month per child |

| Income limit | Yes. 3,604,000 + 380,000 * N (same as ikusei single-parent variant) |
| Exclusion | de-facto spouse, facility admission |
