# 台東区出産費用助成制度 — 出典固定

**状態: VERIFIED（2026-06-22, 台東区公式ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 助成額 | 産婦1人につき一律50,000円 |
| 対象 | 出産日当日に台東区内に住民票がある産婦 |
| 申請期限 | 出産日から1年間 |
| 流産・死産 | 妊娠12週（85日）以降は対象 |
