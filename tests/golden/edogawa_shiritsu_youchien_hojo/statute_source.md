# 江戸川区私立幼稚園補助 — 出典固定

**状態: VERIFIED（2026-06-21, 公式ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 対象 | 3-5歳（満3歳含む）、区内在住、私立幼稚園在園 |
| 新制度園 | 保育料0円（無償化）+ 特定負担額月7,300円まで補助 |
| 従来制度園 | 保育料月33,000円まで無償化（国25,700+区7,300） |
| 入園料 | 限度額100,000円（年度内1回） |
| 給食費 | 一食395円の間接補助 |

出典（公式ページ全文読み取り）:
- 江戸川区公式: https://www.city.edogawa.tokyo.jp/e047/kosodate/kosodate/hoiku/nitijou/shiritsu.html
- 「保育料について月額33,000円までを無償化」
- 「限度額100,000円の入園料補助」
- 「一食当たり395円の補助」
- 証拠: page_snapshot_2026-06-20.txt

注意: 従来制度園の無償化上限は月33,000円（他区の35,000円と異なる）
