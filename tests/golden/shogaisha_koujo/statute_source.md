# 障害者控除 — 出典固定

**状態: VERIFIED（2026-06-21, 国税庁タックスアンサー全文読み取り + page_snapshot保存）**

| 区分 | 控除額 |
|---|---|
| 障害者 | 27万円 |
| 特別障害者 | 40万円 |
| 同居特別障害者 | 75万円 |

| 項目 | 確定値 |
|---|---|
| 対象 | 納税者本人、同一生計配偶者、扶養親族 |
| 16歳未満 | 扶養控除なしでも障害者控除は適用 |
| 特別障害者の例 | 身体1-2級、精神1級、重度知的障害者 |
