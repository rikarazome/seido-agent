# 住宅リフォーム減税（省エネ改修）— 出典固定

**状態: VERIFIED（2026-06-21, 国税庁タックスアンサー全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 控除額 | A×10% + B×5% |
| A（控除対象限度額） | 250万円（太陽光発電含む場合350万円） |
| B上限 | 1,000万円−A |
| 要件 | 合計所得2,000万円以下、床面積50㎡以上 |
| 適用期間 | R7.12.31まで |
| ローン不要 | 住宅ローンなしでも適用可 |
| 工事費要件 | 標準的な費用が50万円超 |
