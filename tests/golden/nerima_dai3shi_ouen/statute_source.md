# 練馬区第3子誕生祝金 — 出典固定

**状態: VERIFIED（2026-06-22, 練馬区公式ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 支給額 | 第3子以降1人につき10万円 |
| 対象 | 練馬区内住所、第3子以降を出生した保護者 |
| 児童要件 | 18歳到達後最初の3月31日までの児童と同居・養育 |
| 居住要件 | 出生日の1年以上前から練馬区に住民登録 |
| 継続居住意思 | 受給後1年以上練馬区に居住する意思 |
| 申請期限 | 出生日から1年 |
| 支給時期 | 申請月の翌月末に振込 |
