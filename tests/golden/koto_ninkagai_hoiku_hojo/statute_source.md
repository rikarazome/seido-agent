# 江東区認可外保育施設等保育料補助 — 出典固定

**状態: VERIFIED（2026-06-21, 公式ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 対象 | 保育の必要性認定を受けた児童 |
| 3-5歳 | 月37,000円上限（全世帯） |
| 0-2歳 非課税 | 月42,000円上限 |
| 0-2歳 課税 | 区独自補助あり（上限額の範囲内） |
| 対象施設 | 認証保育所、家庭福祉員、認可外、ベビーシッター等 |

- 「3歳～5歳児は37,000円／月を上限」
- 「0歳～2歳児は42,000円／月を上限」
- 「0歳～2歳児の住民税課税世帯への補助」もあり
