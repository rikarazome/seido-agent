# 高等職業訓練促進給付金 — 出典固定

**状態: VERIFIED（2026-06-15）**

| 項目 | 確定値 |
|---|---|
| 支給額 | 月額100,000円（住民税非課税世帯）/ 70,500円（課税世帯）。最終年は+40,000円加算 |
| 対象 | ひとり親家庭の親で、看護師・介護福祉士・保育士等の資格取得のため1年以上の養成機関で修業中 |
| 所得制限 | 児童扶養手当の所得制限に準じる |
| 訓練要件 | 1年以上の養成機関で修業中であること |

出典:
- こども家庭庁: https://www.cfa.go.jp/policies/hitori-oya/koto-shokugyo-kunren
- 母子及び父子並びに寡婦福祉法 第31条

判定に使うaskable:
- `hitorioya`: ひとり親か
- `hikazei`: 住民税非課税世帯か（金額決定に使用）
- `nenshu` / `shotoku_exact`: 所得（児童扶養手当の所得制限に準じる）
- `fuyou_ninzu`: 扶養人数

v1簡略化:
- 「養成機関で修業中」の判定はaskableキーとして持たない。
  ひとり親+所得制限以内なら「対象の可能性があります（養成機関での修業が条件）」として案内
- 金額は住民税非課税世帯の100,000円で表示
- 児童扶養手当の所得制限: 全部支給限度額を流用（1,490,000 + 380,000*N）
