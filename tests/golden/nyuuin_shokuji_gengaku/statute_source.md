# 入院時食事療養費の標準負担額減額 — 出典固定

**状態: VERIFIED（2026-06-22, WebSearch調査。専用HTMLページなし、厚労省告示・PDFに記載）**

| 項目 | 確定値 |
|---|---|
| 概要 | 住民税非課税世帯等の入院時食事代が減額 |
| 手続き | 限度額適用・標準負担額減額認定証の交付を受けて提示 |
| 具体的な標準負担額 | 厚労省告示に基づき定められる（HTMLページに記載なし） |
| R9.4変更 | 原則+20円/食、低所得は0～10円 |
