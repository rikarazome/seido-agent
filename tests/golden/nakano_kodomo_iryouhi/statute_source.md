# 中野区子ども医療費助成制度 — 出典固定

**状態: VERIFIED（2026-06-21, 公式ページ全文読み取り + page_snapshot保存）**

| 項目 | 確定値 |
|---|---|
| 対象年齢 | 0歳～18歳到達後最初の3月31日まで |
| 助成内容 | 保険診療の自己負担分を助成（in_kind） |
| 要件 | 中野区住民登録 + 国内健康保険加入 |
| 所得制限 | なし（「所得制限はありません」と明記） |
| 除外 | 生活保護、児童福祉施設入所、里親委託 |
| 注意 | 入院時食事療養標準負担額は対象外 |

- 中野区公式: https://www.city.tokyo-nakano.lg.jp/kosodate/kosodatesite_ohirune/mokuteki/teate/iryohijyosei/kodomoiryojyosei.html
