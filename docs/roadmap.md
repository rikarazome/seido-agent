## 審査で見せる画
1. 基本情報だけ入力 → 知らない給付金が根拠条文リンク付きで即出る
2. 一問一答: 選択肢タップのたびに金額が増えていく。「この1問で2制度確定します」= 質問の必然性
3. 証明木: 「なぜ該当するのか」を条文ベースで提示
4. （可能なら）法改正を模したルール変更 → 判定が変わる = 「まわす」の実演
5. （ストレッチ）第2自治体をパイプラインで追加 → 限界費用の低さ = スケールする「まわす」
