# 対象制度の選定（2026-06-10決定・ドラフト)

調査に基づくMVP対象: **渋谷区 × 子育て世帯 × 10制度**

自治体は渋谷区を第一候補とする（独自制度が多様・例規集で要綱全文公開・Civichatの実証実験があった土地でもありストーリー性がある）。
