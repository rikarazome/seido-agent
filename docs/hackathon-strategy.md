## 審査基準別の見せ方

### つくる（必然性）
- ❌「便利な制度検索チャットボット」に見えたら負け
- ✅ 必然性の三段論法: お金と法律でハルシネーションは致命的 → 形式推論で保証 → 形式化・検証・質問生成は自律エージェントでしか回らない
- 質問生成の根拠（blocked→未収集事実→次の質問）は「自律的な振る舞い」の直接の証拠。デモで必ず見せる

### まわす（最大の得点源にする）
- 二重ループを図解: 内側=ソフトウェアCI/CD、外側=**ルールベースのCI/CD（条文→形式化→golden検証→デプロイ→法改正検知→diff→再検証）**
- デモ: 条文を1行「改正」→ パイプラインが回ってルールdiff＋判定変化＋全goldenパス → 数十秒で見せる
- 判定精度のモニタリング（Cloud Trace + 検証パス率）

### とどける
- Cloud Runで公開、審査期間中の安定稼働（コールドスタート・コスト設計を記事に明記）
- 個人情報の扱い: 世帯情報はセッション限り・保存しない設計を明示
